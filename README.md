# Vehicle Rental Management System

## Project Description

The Vehicle Rental Management System is a web-based application developed to simplify the process of renting vehicles such as cars and bikes. Users can create an account, log in, browse available vehicles, search and filter vehicles, book a vehicle for selected dates, and view their booking history.

The system will also provide an admin section for managing vehicles and bookings.

## Problem Statement

Traditional vehicle rental processes may require customers to manually contact rental providers to check vehicle availability and make bookings. This can take time and may result in booking conflicts.

The Vehicle Rental Management System provides a simple online platform where users can view vehicles, check their availability, and make bookings based on selected rental dates.

## Objectives

- Develop a simple web-based vehicle rental system.
- Provide user registration and login.
- Display available cars and bikes.
- Allow users to search and filter vehicles.
- Allow users to book vehicles for selected dates.
- Track vehicle availability.
- Maintain user booking history.
- Provide an admin section for vehicle and booking management.
- Prevent conflicting bookings using date-based availability validation.

## Target Users

### Customers
Customers can register, log in, browse vehicles, check availability, make bookings, and view their booking history.

### Administrator
The administrator can manage vehicles and monitor bookings.
